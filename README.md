Titanic Survival Prediction

Celem projektu jest analiza danych pasażerów statku Titanic oraz budowa modeli uczenia maszynowego umożliwiających przewidywanie przeżycia pasażera na podstawie dostępnych informacji.

Projekt został wykonany w języku Python z wykorzystaniem bibliotek służących do analizy danych oraz uczenia maszynowego.

Wykorzystane technologie
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

Zakres projektu

W ramach projektu przeprowadzono:

- Eksploracyjną analizę danych (EDA)
- Analizę brakujących wartości
- Preprocessing danych
- Kodowanie zmiennych kategorycznych
- Analizę korelacji pomiędzy zmiennymi
- Podział danych na zbiór treningowy i testowy
- Budowę modeli klasyfikacyjnych
- Ocenę skuteczności modeli
- Analizę ważności cech

Zastosowane modele:
- Regresja logistyczna - Model liniowy wykorzystywany do problemów klasyfikacji binarnej.

- Random Forest - Model oparty na zespole drzew decyzyjnych, umożliwiający wykrywanie bardziej złożonych zależności w danych.

Wyniki

Skuteczność modeli została oceniona przy użyciu następujących metryk:

- Accuracy
- Precision
- Recall
- F1-score
- ROC AUC

Porównanie wyników pozwoliło określić model najlepiej radzący sobie z przewidywaniem przeżycia pasażerów.

Najważniejsze wnioski:
- Wybrane cechy pasażerów pozwalają skutecznie przewidywać prawdopodobieństwo przeżycia.
- Płeć, wiek oraz klasa podróży należą do najistotniejszych czynników wpływających na przeżycie.
- Modele uczenia maszynowego osiągnęły wysoką skuteczność klasyfikacji.
- Analiza ważności cech pozwoliła określić zmienne mające największy wpływ na decyzje modelu.
